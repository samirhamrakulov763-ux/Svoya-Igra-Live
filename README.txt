СВОЯ ИГРА — мультиплеерная викторина
1. Дважды нажмите «Запустить игру.cmd». Не закрывайте окно сервера во время игры.
2. На этом компьютере откройте http://localhost:4173
3. Нажмите «Ведущий» и введите PIN из файла data\config.json (поле pin).
4. На телефонах и других компьютерах той же Wi-Fi-сети откройте http://192.168.1.7:4173 (IP может измениться).
5. Игроки вводят только имя. Ведущий выбирает ячейку, назначает отвечающего, нажимает «Правильно» или «Неправильно».
6. При неправильном ответе очки снимаются, активность переходит следующему игроку. Вопрос остаётся открытым.
7. Ведущий может показать ответ, включить таймер, изменить баллы вручную, редактировать категории и вопросы, начать новый раунд или сбросить игру.
8. Данные автоматически сохраняются в data\game.json. Не удаляйте эту папку.

ИНТЕРНЕТ: для входа извне локальной Wi-Fi-сети нужен отдельный защищённый хостинг/VPN. Не открывайте порт роутера в Интернет без дополнительной защиты.

Требуется Node.js 18+; дополнительные npm-пакеты не нужны.

ПУБЛИЧНЫЙ ДОСТУП ЧЕРЕЗ ИНТЕРНЕТ (БЕСПЛАТНО)
1. Сейчас игра доступна по HTTPS-ссылке Cloudflare Quick Tunnel (адрес был передан в ChatGPT).
2. Компьютер, игровой сервер и cloudflared должны оставаться включены. Отключение любого из них прерывает игру.
3. Если туннель остановится, запустите «Публичный доступ.cmd». Новую ссылку *.trycloudflare.com ищите в окне туннеля.
4. Ссылка временная и меняется при перезапуске туннеля. Для постоянного хостинга нужен отдельный хостинг и надёжное сохранение данных игры.
5. PIN ведущего хранится в data\config.json, не показывайте этот файл игрокам.
